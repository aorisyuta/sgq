# UniBoard SPICE

ブラウザだけで動く電子工作 CAD です。元の **UniBoard CAD**（回路図 → ユニバーサル基板パターン図）の機能はそのまま残し、見た目を一新して次の機能を追加しました。

`index.html` を開くだけで使えます（1 ファイル・インストール不要）。

## 機能

| 画面 | できること |
|---|---|
| 回路図 | 部品配置・配線（元の機能）＋ 5,655 点の部品ライブラリ検索、プローブ |
| シミュレーション | SPICE 互換エンジン：動作点 / 過渡解析 / AC 解析（ボード線図）/ DC スイープ、FFT、波形の計測（最大・最小・実効値・周波数・−3dB）、回路図上の電圧表示と LED 点灯アニメーション、ネットリストの直接編集（.cir 読み込み） |
| 蛇の目基板 | 元の機能（自動配置・2 層配線・ストリップボード・配線指示） |
| PCB | 回路図から読み込み、自動配置、手動配線（45°・ビア）、2 層自動配線、ベタ GND、DRC、ガーバー一式 ZIP・ドリル・BOM・実装座標 CSV の出力 |
| 計算ツール | オームの法則、LED 抵抗、カラーコード、分圧、555、RC/LC、LM317、オペアンプ、配線幅、コンデンサ表示、E 系列、dB、電池、AWG |

### 美しい配線（蛇の目基板・PCB の自動配置と自動配線）

「基板に変換」の設定「美しい配線: 厳守（推奨）」で、次の 3 つを守って配置・配線します（PCB の自動配置・自動配線も同じ方針です）。

1. **配線を短く、特に GND を最短に**: GND・電源の配線長を重く見て部品を置き、GND から先に配線します。
2. **同じ働きの部品を一か所に**: IC・トランジスタを中心に、信号線でつながる抵抗・コンデンサなどを「機能ブロック」としてまとめ、ブロックどうしが混ざらないように置きます（基板上に枠で表示）。
3. **枝分かれしない一筆書き**: 3 か所以上をつなぐ配線は、パッドからパッドへ一筆書きの順に引き、線の途中から枝分かれさせません。

配置を何通りか作り、最も美しいもの（未配線なし → 枝分かれ・GND 長・ブロックの混在・全長・曲がりが少ない順）を採用します。結果は「プロパティ」の「美しい配線のチェック」に表示されます。
`node tests/beauty.test.js` でサンプル回路の従来方式との比較が出ます。

### パターン図の手動調整

出力された蛇の目基板（自動変換・手配置どちらも）の部品を、**ドラッグで移動**、選んで **R**（または「↻ 回転」）で回転できます。部品の追加・削除はできません（回路図で行います）。
動かすたびに、その部品につながる配線と新しい位置とぶつかる配線だけを自動で引き直します（他の配線はそのまま。引き直せないときは全体を配線し直します）。
重なる場所・基板の外には置けません。「元に戻す / やり直し」（Ctrl+Z / Ctrl+Y）あり。調整した結果は「配置を保存」で回路図 JSON に保存できます。

### 蛇の目基板の配線をそのまま読み込む

回路図 JSON に `perfboard` を書くと、「蛇の目基板」タブで自動配置・自動配線をせず、その部品位置と配線のまま表示します（DRC・配線指示・画像出力もそのまま使えます）。表示中の基板は「配置を保存」で JSON に書き戻せます。

```json
"perfboard": {
  "cols": 15, "rows": 10,
  "parts": { "R1": { "1": "C4", "2": "F4" }, "Q1": { "E": "E1", "C": "E2", "B": "E3" } },
  "wires": [ { "layer": "solder", "pts": ["B4", "C4"] },
             { "layer": "component", "pts": ["D2", "D6"] },
             { "layer": "insulated", "pts": ["A1", "H9"] } ]
}
```

穴は `A1` 形式（列は英字・行は数字、アプリの配線指示と同じ）か `[列, 行]`（0 始まり）。`solder` = 半田面のすず線（縦・横・45°）、`component` = 部品面ジャンパ、`insulated` = 被覆線。例: `examples/iraira-stick.json`。

画面は Web 版・Android アプリとも Material Design 3（Android の標準デザイン）です。旧デザインは URL に `?ui=classic` を付けると表示できます（PC のみ）。

ショートカット: `Ctrl+K` コマンド検索、`F5` シミュレーション実行、`1/2/3` 画面切替、`?` 一覧。

## Android アプリ

`dist/UniBoardSPICE.apk`（Android 7.0 以上）。スマホで開いてインストールしてください（「提供元不明のアプリ」の許可が必要です）。
中身は同じ `index.html` を WebView で表示するアプリで、保存は Android の保存先選択画面、読み込みはファイル選択画面を使います。戻るボタンは開いている画面を順に閉じます。

作り直すとき: `python3 android/build.py`（Android SDK は不要。Maven Central から android-all / dx / apksig を取得して組み立て・署名します）。
署名鍵 `android/uniboard-release.p12` を変えると、上書きインストールできなくなります。

## 開発

```
src/base.html        元の UniBoard CAD（フックを追加）
src/js/spice.js      SPICE エンジン（MNA + ニュートン法 + 台形積分）
src/js/spice-models.js  ロジック IC などの動作モデル
src/js/parts-*.js    追加記号と部品カタログ
src/js/sim-netlist.js  回路図 → ネットリスト
src/js/simui.js      シミュレーション画面
src/js/pcbx.js       PCB 設計・ガーバー出力
src/js/calc.js / shell.js / ui-pre.js  計算ツール・検索・自動保存など
src/css/app.css      新しい見た目
src/js/perf-edit.js  蛇の目基板の手動調整（移動・回転・部分的な引き直し）
src/css/md.css / src/js/md.js / md-pre.js  Material Design 3（アプリバー・ナビゲーション・FAB・ボトムシート）
```

`node build.mjs` で `index.html` を生成します。テスト: `node tests/spice.test.js`、`node tests/netlist.test.js`（Playwright の画面テストは `tests/*.mjs`）。
